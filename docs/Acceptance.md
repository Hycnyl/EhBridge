# EhBridge 1.1.1 变更与验收

版本 1.1.1，versionCode 3，包名 `com.hycnyl.ehbridge`。继续提供简体中文与 English，一个已签名 universal APK 覆盖 arm64-v8a、armeabi-v7a、x86、x86_64，最低 Android 8.0。

## 修改前备份

编辑前已备份并逐项校验当前 1.1.0 源码、私有签名配置和全部原交付物。完整私有备份：`/workspace/backups/EhBridge-1.1.0-20261023-104748.tar.gz`。后续修改前继续执行备份要求。

## 本次修改

1. 普通启动图标的文件夹和双向箭头以画布中心为轴，统一缩小至原来的 90%；主体外接范围从 60×51dp 调整为 54×45.9dp，背景尺寸与颜色保持原样。主题图标的 monochrome 资源与 1.1.0 字节一致。
2. 有合法数字页文件的散图画廊，缺少 `.ehviewer` 时仍可扫描、复制或打包；新增 MISSING_EHVIEWER 非阻断提示，并接入独立开关、详情和报告。没有状态文件时不再额外提示“原下载状态未转移”。散图同格式复制不会编造状态文件；B→A 仍生成 CBOR SpiderInfo。空画廊、混合布局、未映射数据等阻断规则保留。
3. 菜单末项改为“关于 / About”。先展示软件信息及实际版本、作者 Hycnyl、项目 GitHub，之后依次提供选目录、扫描、开始处理、格式结构、可选文件、兼容性和隐私报告七节指南。作者与项目卡片交由外部浏览器打开，无法启动浏览器时显示本地化提示。

作者链接：`https://github.com/Hycnyl`。
项目链接：`https://github.com/Hycnyl/EhBridge`。
两者均按用户提供值写入，未访问或检查其可用性。

图标参考：[Android 官方自适应图标指南](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive?hl=en)。参考其 108dp 图层、48–66dp 标志尺寸建议与安全区域说明，在保留文件夹原有宽高比例的前提下进行适度缩放。

## 最小验证

- 新增两项临时逻辑回归：缺 `.ehviewer` 且其它侧车也缺失时，PACK／COPY 成功、页字节保留、源文件不变；空目录、未知额外文件、同名状态目录仍被正确阻断，已有 `.ehviewer` 的提示策略维持正常。
- 另运行原有五项快速核心回归一次。共 7 项，全部通过，累计运行 0.508 秒。
- 两套文案各 138 项，键名、占位符及新增内容一致；“关于”三块信息顺序、链接常量、普通图标缩放参数及主题单色资源保持情况检查通过。
- `testDebugUnitTest`、`assembleRelease`、`lintRelease` 单次构建成功，lint 无错误。
- APK 版本、包名、原发布证书、四种 ABI、ZIP 16KiB 对齐及所有 native ELF LOAD 段至少 16KiB 对齐均已核对。Release 不包含调试测试提供器，也没有新增网络或全盘存储权限。

本次没有启动模拟器，没有重跑数百画廊压力测试，也没有查看画廊图片。新增临时测试类及生成数据在验证后清除；原有维护用测试保留。验收记录保存在 `docs/verification/v1.1.1/`，源码交付不含签名私钥、签名密码或原始用户样本。
